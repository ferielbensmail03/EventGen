How it works

From a title to a story, word by word

EventGen is a sequence-to-sequence neural network implemented and trained from scratch in PyTorch on French event descriptions. No pretrained language model, no external generative AI API.

  1. 01

    Serialise

    Type labels and title become one line: type : concert , musique | titre : …

  2. 02

    Tokenise

    Lower-cased, French elisions split, words mapped to ids. Unseen words become <unk>.

  3. 03

    Encode

    128-d embeddings feed a 256-unit LSTM that reads the whole input.

  4. 04

    Attend

    At every step, additive attention scores each input word: c(t) = Σ α(t,i)·hᵢ.

  5. 05

    Decode

    An LSTM decoder starts from <sos> and predicts P(yₜ | y<ₜ, X), feeding back its own words.

  6. 06

    Search

    Greedy or beam search picks the words until <eos>, then the text is detokenised.

About the model

EventGen does not call any external generative service. Two encoder–decoders were trained here, on DATAtourisme — the French national open-data feed of tourist events — to learn P(description | type, title).

The baseline squeezes the whole input into the encoder's final state. The attention model can look back at any input word while writing, which helps it reuse words from the title.

Honest limits

  • A small model trained on ~26k examples: expect generic phrasing and occasional repetition.
  • It only knows the event type and title — any date, place or price it writes is invented by the model.
  • Attention weights show where the model looked, not a full explanation of why.
